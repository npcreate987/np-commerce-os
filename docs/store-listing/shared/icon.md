# App Icon — Spec

## Apple App Store

- **Size**: 1024 × 1024 px (PNG, no transparency, no rounded corners)
- **Location**: App Store Connect → App Information → App Icon
- **iOS rendering**: 60pt @3x → 180px, generated automatically from
  the 1024 master by `@capacitor/assets` (Phase 15 pipeline)

## Google Play Store

- **Size**: 512 × 512 px (PNG with alpha)
- **Location**: Play Console → Main store listing → Icon
- **Android rendering**: adaptive icon (foreground + background) →
  generated by `@capacitor/assets`

## Master Vector

ทุก size generate มาจาก master:

```
apps/web/resources/logo.svg
```

(Phase 15 — ห้ามใส่ Thai characters ในคอมเมนต์ SVG เพราะ sharp parse ไม่ผ่าน)

## Design Constraints

- ✅ Brand pink solid `#FF3E5C` background
- ✅ "NP" monogram, light weight (Anuphan Bold @ 70pt)
- ✅ ไม่มี text ที่อ่านไม่ออกที่ 60×60 px
- ❌ ไม่มี gradient ที่อ่อนเกินไป (Apple lint)
- ❌ ไม่มีตัวหนังสือยาวกว่าทรงสี่เหลี่ยม (Google adaptive icon crop)
